# React + Vite
MotoGrid is a React-based e-commerce admin portal for selling cars.

## Features

- Home page
- View all cars
- Search cars
- Add new car
- Edit car details
- Delete car
- React Router navigation
- Context API
- Custom hook
- JSON Server backend
- Testing with React Testing Library

## Technologies Used

- React
- React Router
- JSON Server
- CSS
- Git and GitHub
- Jest
- React Testing Library
